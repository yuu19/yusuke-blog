# PatternRecognition

ソース:

- https://github.com/freqtrade/freqtrade-strategies/blob/debc6d9c22fd7b4dfe939441bf2bd39ede4f86c4/user_data/strategies/PatternRecognition.py
- class: `PatternRecognition`
- 配置: `標準 strategies`

## まず何の戦略か

TA-Lib の pattern recognition を総当たりで使う実験戦略です。価格行動を離散ラベルとして扱います。

## 設定の骨格

- timeframe: `1d`
- 読み味: 日足のポジション保有向き
- stoploss: `-0.288`
- minimal_roi: `0: 0.936, 5271: 0.332, 18147: 0.086, 48152: 0`
- `can_short`: `false`
- 特殊メソッド: `なし`

## 実装上のポイント

- 戦略タイプ: 汎用テクニカル系
- 主な指標: `ほぼなし / 実装依存`
- 読みどころ: 日足で全 candlestick pattern を列展開し、選択パターンが特定値を取るときだけ entry する構造です。

## 実戦での注意点

パターン検出は過学習しやすいので、日足でも walk-forward 検証が必須です。

## この戦略を読むときの着眼点

`populate_indicators()` でどの列を作り、`populate_entry_trend()` / `populate_exit_trend()` がそれをどう組み合わせているかを順に追うと、設計思想が読みやすくなります。

特に `1d` では signal の速さとノイズ耐性のトレードオフが強く出ます。`minimal_roi` と `stoploss` をセットで見て、どれくらいの保持時間と損失幅を許す設計なのかを先に掴むのが有効です。
