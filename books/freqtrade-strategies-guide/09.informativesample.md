# InformativeSample

ソース:

- https://github.com/freqtrade/freqtrade-strategies/blob/debc6d9c22fd7b4dfe939441bf2bd39ede4f86c4/user_data/strategies/InformativeSample.py
- class: `InformativeSample`
- 配置: `標準 strategies`

## まず何の戦略か

informative pairs の基本形で、取引対象以外の市場を参照してフィルタする実装例です。

## 設定の骨格

- timeframe: `5m`
- 読み味: 短期執行向き
- stoploss: `-0.1`
- minimal_roi: `60: 0.01, 30: 0.03, 20: 0.04, 0: 0.05`
- `can_short`: `false`
- 特殊メソッド: `informative_pairs`

## 実装上のポイント

- 戦略タイプ: informative / MTF サンプル
- 主な指標: `EMA`
- 読みどころ: 5m の対象銘柄 EMA と 15m の BTC/USDT SMA を組み合わせ、参照市場の地合いで entry を絞ります。

## 実戦での注意点

性能目的ではなく data provider と merge_informative_pair の使い方を学ぶ章として読むべきです。

## この戦略を読むときの着眼点

`populate_indicators()` でどの列を作り、`populate_entry_trend()` / `populate_exit_trend()` がそれをどう組み合わせているかを順に追うと、設計思想が読みやすくなります。

特に `5m` では signal の速さとノイズ耐性のトレードオフが強く出ます。`minimal_roi` と `stoploss` をセットで見て、どれくらいの保持時間と損失幅を許す設計なのかを先に掴むのが有効です。
