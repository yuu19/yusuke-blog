この本は、[`freqtrade/freqtrade-strategies`](https://github.com/freqtrade/freqtrade-strategies) に含まれる戦略実装を、各戦略ごとに1ページで読み解くガイドです。

## 前提

このリポジトリは教育用サンプル集です。したがって、全てをそのまま本番投入候補として読むべきではありません。

- `lookahead_bias/`: 高成績より、検証ミスや future leak の危険を理解するための教材
- `futures/`: 先物・ショート対応のサンプル群。現物より資金管理の比重が大きい
- `BreakEven`, `CustomStoplossWithPSAR`, `FixedRiskRewardLoss`, `InformativeSample`, `multi_tf`: API や拡張ポイントを学ぶ章
- `DoesNothingStrategy`, `TechnicalExampleStrategy`: 雛形・サンプルとして読む章

## この本でいう「核戦略」とは何か

この本では、単に出来が良い戦略や成績が良さそうな戦略を「核戦略」とは呼びません。ここでの核戦略とは、他の章を読むための土台になる設計パターンを最も分かりやすく含んでいる戦略群を指します。

言い換えると、核戦略を先に押さえると次のような効果があります。

- どの指標を作り、どの条件で entry / exit を組むかという Freqtrade 戦略の基本骨格が見える
- 順張り、逆張り、押し目拾い、ブレイクアウトの違いを比較しやすくなる
- `berlinguyinca/` や `futures/` に出てくる派生戦略が、何を足して何を削った版なのか追いやすくなる
- `custom_stoploss`, `informative_pairs`, MTF のような拡張点を、基礎戦略と切り分けて理解しやすくなる

## 先に押さえるべき核戦略

### 1. 基本骨格を掴む核: `Strategy001` から `Strategy005`

この 5 本は、この本の出発点です。理由は単純で、Freqtrade の戦略クラスが何を持ち、どこで売買条件を定義し、ROI / stoploss / timeframe がどう噛み合うかを最短で確認できるからです。

- `Strategy001`: informative pair や Heikin Ashi を含み、単純な売買条件の上に「補助情報をどう足すか」を学びやすい
- `Strategy002`: オシレーター寄りの判定が増え、トレンド追従一辺倒ではない条件設計を読める
- `Strategy003`: インジケータの組み合わせを少し複雑にしたときの読み方の練習になる
- `Strategy004`: ブレイクやモメンタムの読み味が強く、速度重視の条件設計を比較しやすい
- `Strategy005`: 複数条件をまとめたときに、どこで過剰最適化が入りやすいかを観察しやすい

この章群は「最強戦略候補」ではなく、「Freqtrade 戦略を読むための文法書」として読むのが適切です。

### 2. 相場観を作る核: `Bandtastic`, `Supertrend`, `hlhb`, `UniversalMACD`

この 4 本は、相場の取り方の違いを比較するための核です。ここを押さえると、同じテクニカルでも戦略思想がかなり違うことが見えてきます。

- `Bandtastic`: ボラティリティ帯を軸に、伸びすぎや押し戻しをどう扱うかを見る
- `Supertrend`: 地合い方向を先に決め、その流れに沿って入る順張りの基本形として読める
- `hlhb`: 移動平均と価格位置の関係から、比較的素直なトレンド継続を拾う設計
- `UniversalMACD`: モメンタム転換やクロス系の発想を、より古典的なテクニカルで確認できる

この 4 本を並べて読むと、「トレンドを追う」と言っても、ボラティリティ帯で測るのか、方向指標で測るのか、価格と平均線の位置関係で測るのか、オシレーターの転換で測るのかが違うと分かります。

### 3. 拡張ポイントを掴む核: `InformativeSample`, `multi_tf`, `CustomStoplossWithPSAR`, `FixedRiskRewardLoss`

これらは勝ち筋そのものより、Freqtrade の拡張余地を理解するための核です。

- `InformativeSample`: 別 timeframe / 別ペアの情報を持ち込むと、戦略の見ている世界がどう広がるかを示す
- `multi_tf`: MTF 設計をより直接的に扱い、上位足フィルタの考え方を掴みやすい
- `CustomStoplossWithPSAR`: entry 条件と損切りロジックを分離して読む練習になる
- `FixedRiskRewardLoss`: リスクリワード主導で exit を設計するときの骨格が見える

実戦では entry ロジックだけでなく、ポジションをどう切るかが成績を大きく左右します。そのため、このグループは「後回しでもよい応用」ではなく、核戦略の一部として先に触れておく価値があります。

### 4. 派生戦略を読むための核: `berlinguyinca/` と `futures/` の母体

`berlinguyinca/` 配下は数が多いですが、全部を最初から均等に読む必要はありません。まずは核になる数本を拾い、その派生を追う読み方が効率的です。

- `ADXMomentum`, `AdxSmas`: トレンド強度と平均線の組み合わせを見る母体
- `MACDStrategy`, `AwesomeMacd`: MACD 系の発想を比較する母体
- `BbandRsi`, `Low_BB`: ボリンジャーバンド系逆張りの母体
- `Quickie` と `ReinforcedQuickie`: 元戦略と強化版を比較する教材
- `SmoothScalp` と `ReinforcedSmoothScalp`: スキャルピング系の改良パターンを追う教材

また `futures/` は、現物戦略の焼き直しではなく、long / short の対称性、資金管理、シグナル反転時の扱いが主題です。したがって、現物の核戦略を理解してから入ると、「何が先物対応で追加された論点なのか」が見えやすくなります。

## 読む順番のおすすめ

1. `Strategy001` から `Strategy005` で Freqtrade の基本形を掴む
2. `Bandtastic`, `Supertrend`, `hlhb`, `UniversalMACD` で順張り・逆張りの違いを比較する
3. `InformativeSample`, `multi_tf`, `CustomStoplossWithPSAR`, `FixedRiskRewardLoss` で拡張ポイントを掴む
4. `berlinguyinca/` で定番インジケータの組み合わせパターンを広く見る
5. `futures/` で long/short の対称設計を確認する
6. `lookahead_bias/` で検証リテラシーを学ぶ
