OAuth + OpenID Connect

認可の上にidentity layerを重ねる

同じflowでもAccess TokenとID Tokenは受取人も用途も違う。

OAUTH LAYER

Access Token → Resource API

  • notes:read / notes:write
  • aud = Notes API
  • API operationを認可

OIDC LAYER

ID Token → Client

  • openid + nonce
  • aud = Client ID
  • authentication eventを検証
Authorization Code：Clientが交換
Access Token：RSへ提示
ID Token：Clientだけが検証
